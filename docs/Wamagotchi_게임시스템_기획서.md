# 1. 정령 시스템

## 1.1 이름 결정 (유저 자유 입력) ★확정 사양

정령의 이름은 게임이 정해 주지 않는다. **유저가 직접 지어 주는 순간이 교감의 시작점**이다.

| 항목 | 규칙 |
|---|---|
| 입력 시점 | 알이 부화하는 연출 직후, "이름을 지어 주세요" 입력창 표시 |
| 글자 수 | 1~8자 |
| 허용 문자 | 한글, 영문, 숫자 (중간 공백 1개 허용, 앞뒤 공백 자동 제거) |
| 필터 | 금칙어(욕설·비속어) 사전 필터. 로컬 게임이므로 중복 검사는 없음 |
| 이름 뽑기 | 입력창 옆 🎲 버튼: 랜덤 후보 제시 (예: 잉크, 모모, 도트, 먹물, 쉼표, 나기, 픽셀, 심야) |
| 개명 | 상점 아이템 **[정령의 이름표]**(3,000 M) 사용 시 언제든 변경 가능. 횟수 제한 없음 |
| 기록 | 명예의 전당에는 **은퇴 시점의 이름**으로 기록된다 |
| 활용 | 모험 로그·편지·대사·유산 장비명 등 게임 내 모든 텍스트에 `{이름}` 변수로 노출 |

> 부화 조건: 알 상태(Lv.1~4)에서 **첫 메모들을 작성해 Lv.5 도달 시 부화** (약 270자 = 첫날 안에 자연 달성).
> "글을 써야 태어난다"는 콘셉트를 온보딩에서부터 체험시킨다.

## 1.2 종족 시스템 (세대교체 연동)

환생(9장)마다 새로운 종족의 알을 선택할 수 있다. 종족은 **기본 스탯 보정 + 고유 특성 + 속성**을 가진다.

| 종족 | 해금 | 속성 | 스탯 보정 | 고유 특성 |
|---|---|---|---|---|
| 그림자 정령 | 기본 (1세대) | 그림자 | 균형 | **메아리**: 키워드 이벤트 발동률 +10% |
| 불꽃 정령 | 환생 1회 | 불 | ATK +10% | **연소**: 전투 승리 시 마나 +10% |
| 물방울 정령 | 환생 1회 | 물 | HP +15% | **촉촉함**: 포만감 자연 감소 −10% |
| 바람 정령 | 환생 2회 | 바람 | AGI +15% | **순풍**: 탐험 틱 주기 −10% |
| 이끼 정령 | 환생 2회 | 땅 | DEF +15% | **광합성**: 휴식 룸 효과 2배 |
| 유리 정령 | 환생 3회 | 무(투명) | CRIT +15%, HP −10% | **투명한 마음**: 감정 키워드 효과 +50%, 속성 상성 무시 |
| 별빛 정령 | 환생 4회 | 빛 | INT +10% | **야광**: 실제 시간 밤(21~06시)에 전 스탯 +10% |
| 기계 정령 | 환생 5회 | 기계 | LUK +10% | **자동화**: 오프라인 정산 상한 +4시간, 속성 상성 무시 |

## 1.3 성격 시스템

부화 시 10종 중 1개가 **랜덤 부여**된다. 성격은 소소한 보정과 함께 **로그 말투·이벤트 반응**을 바꿔,
같은 종족이라도 "내 정령"만의 개성을 만든다. (환생 시 재추첨, [성격 교정 티켓]으로 변경 가능)

| 성격 | 게임 효과 | 말투/연출 특징 |
|---|---|---|
| 성실함 | 일일 의뢰 보상 +10% | 존댓말, 보고서 스타일 로그 |
| 먹보 | 포만감 회복 +10%, 자연 감소 +5% | 모든 로그가 음식 비유 |
| 겁쟁이 | 함정 회피 +20% | 덜덜 떠는 말줄임표 다용 |
| 호기심 | 수수께끼·균열 룸 발견률 +50% | 감탄사와 물음표 다용 |
| 낙천적 | 시무룩 상태 진입 기준 완화 (포만 20%→10%) | 나쁜 일도 긍정 해석 |
| 새침함 | 쓰다듬기 친밀도 절반, 편지 친밀도 2배 | 츤데레 어투 |
| 수집광 | 재료 아이템 드롭 +10% | 전리품 자랑 로그 |
| 잠꾸러기 | 오프라인 정산 상한 +2시간, 탐험 속도 −5% | 하품, 늘어지는 어미 |
| 열혈 | ATK +5%, DEF −3% | 전투 로그가 유독 뜨거움 |
| 몽상가 | INT +5%, 함정 회피 −10% | 시적인 표현, 딴생각 |

## 1.4 성장 단계

| 단계 | 레벨 | 외형/이벤트 |
|---|---|---|
| 알 | Lv.1~4 | 금 가는 연출. 글을 쓸수록 흔들림 |
| 부화 (유년기) | Lv.5 | **이름 입력 이벤트.** 꼬마 정령 등장 |
| 1차 성장 | Lv.15 | 몸집 커짐, 소지품(막대기 등) 생김 |
| 2차 진화 | Lv.30 | **클래스 확정** (2.2 작업 패턴 판정). 외형이 클래스별로 분화 |
| 3차 전직 | Lv.60 | 전직 시련(2.3) 통과 시 상위 클래스. 외형에 상징물 추가 |
| 각성 | Lv.90 | 스프라이트에 발광/오라 이펙트. 전 스탯 +5% |
| 은퇴 가능 | Lv.100 | 환생 시스템 개방 (9장) |

## 1.5 기분(Mood) 시스템

포만감과 별개로, 정령의 **현재 감정 상태**를 표시한다. 상태창 표정과 로그 말투에 반영된다.

| 기분 | 진입 조건 | 효과 |
|---|---|---|
| 신남 😆 | 오늘 저장 3회 이상 또는 친밀도 이벤트 직후 | 마나 획득 +10% |
| 평온 🙂 | 기본 상태 | — |
| 심심함 😐 | 24시간 무저장 | 탐험 속도 −10%. 쓰다듬기에 크게 반응 |
| 시무룩 😢 | 포만감 20% 미만 | 마나 획득 −10% |
| 기절 😵 | 포만감 0% | 탐험 정지 (사망 아님. 글을 쓰면 즉시 회복 시작) |
| 겨울잠 💤 | 7일 이상 무접속 | 탐험 정지. 복귀 시 재회 연출 + 복귀 선물 (벌칙 없음) |

> **설계 의도**: 벌은 "정지"까지만, 보상은 "가속"으로. 죄책감이 아니라 반가움으로 복귀시킨다.

# 2. 스탯 & 클래스 시스템

## 2.1 7대 스탯

기존 5스탯에 **INT(지능)·LUK(행운)** 을 신설한다.

| 스탯 | 효과 | 주요 성장 수단 |
|---|---|---|
| ATK 공격력 | 전투 승리 확률·처치 속도 가중치 | 레벨업, 무기 |
| DEF 방어력 | 패배 시 후퇴 층수 감소 | 레벨업, 방어구 |
| HP 체력 | 탐험 1회당 진행 가능 층수·연전 지속력 | 레벨업, 방어구 |
| AGI 민첩 | 탐험 틱 단축·회피 | 레벨업, 장신구 |
| CRIT 치명타율 | 치명타(보상 2배)·희귀 드롭 확률 | 클래스, 장신구 |
| **INT 지능** ★신설 | 수수께끼 룸 정답률·마법 스킬 위력 | **어휘 다양성** (아래) |
| **LUK 행운** ★신설 | 드롭률·희귀 룸 조우율 전반 가산 | 업적·칭호·장신구로만 성장 |

> **INT 성장 규칙 — "다양한 어휘가 곧 지능"**
> 저장 시 새로 추가된 텍스트의 **고유 단어 비율**(중복 제외 단어 ÷ 전체 단어)이 60% 이상이면 INT +1 (1일 3회 상한).
> 같은 말을 복붙하는 것이 아니라 풍부하게 쓰는 습관이 정령을 똑똑하게 만든다.

## 2.2 작업 패턴 판정 (확장: 4종 → 6종)

최근 30회 저장 통계로 판정하며, **Lv.30 진화 시점에 확정**된다. 복수 조건 충족 시 **위에서부터 우선**.

| 우선 | 패턴 | 판정 기준 | 2차 클래스 | 특화 |
|---|---|---|---|---|
| 1 | 박식형 ★신설 | INT 30 이상 (어휘 다양성 누적) | **어휘 마도사** | INT, 마법 |
| 2 | 심야형 | 22:00~02:00 저장 비중 40%↑ | **그림자 도적** | CRIT |
| 3 | 아침형 ★신설 | 05:00~09:00 저장 비중 40%↑ | **여명 사제** | 회복·버프 |
| 4 | 단문·다저장형 | 평균 저장 300자 미만 & 일 5회↑ | **암살자** | AGI |
| 5 | 장문·집필형 | 1회 2,000자↑ 저장 비중 30%↑ | **기사** | HP·DEF |
| 6 | 균형형 | 위 조건 미충족 | **모험가** | 전 스탯 균등 |

## 2.3 클래스 트리 (2차 → 3차 전직)

Lv.60 도달 + **전직 시련**(조건 퀘스트) 완료 시 3차 전직. 갈래는 유저가 선택한다.

| 2차 클래스 | 3차 전직 A | 3차 전직 B | 전직 시련 (예) |
|---|---|---|---|
| 모험가 | **방랑 작가** (전 스탯 +5%, 모든 던전 드롭 +5%) | **만능 필경사** (의뢰 보상 +20%) | 서로 다른 던전 5곳 클리어 |
| 그림자 도적 | **나이트 스토커** (CRIT 극대화, 즉살 스킬) | **달빛 무희** (AGI+CRIT 복합) | 심야 저장 누적 30회 + 그림자 속성 보스 처치 |
| 여명 사제 | **태양 음유시인** (버프 지속 2배) | **새벽 성기사** (DEF+회복) | 아침 저장 누적 30회 + 7일 스트릭 |
| 암살자 | **속기 검객** (탐험 틱 −20%) | **바람칼잡이** (2연격) | 하루 8회 저장 달성 5일 |
| 기사 | **대문호 기사** (HP+ATK, 장문 버프 강화) | **서고 수호자** (DEF 극대, 패배 무효 1회/일) | 3,000자 이상 단일 저장 5회 |
| 어휘 마도사 | **사전의 현자** (INT 스킬 위력 2배) | **활자 소환사** (몬스터 1종 동료화) | INT 60 + 수수께끼 룸 10회 정답 |

## 2.4 스킬 시스템 ★신설

전투·탐험 중 **자동 발동**되는 능력. 조작을 요구하지 않는다(방치형 원칙). 클래스 스킬은 Lv.30/45/60에 자동 습득.

**클래스 스킬 예시**

| 클래스 | 스킬 | 효과 |
|---|---|---|
| 모험가 | 길눈 | 탐험 이동 속도 +5% |
| 모험가 | 잡학 | 전 스탯 +2 |
| 그림자 도적 | 급소 찌르기 | 치명타 보상 2배 → 2.5배 |
| 그림자 도적 | 심야의 집중 | 22~02시 CRIT +15% |
| 나이트 스토커 | 일격필살 | 전투를 1틱에 끝낼 확률 10% |
| 여명 사제 | 아침 기도 | 05~09시 저장의 포만감 회복 2배 |
| 암살자 | 저장의 잔상 | 저장 직후 10분간 AGI +20% |
| 기사 | 철벽 | 패배 시 후퇴 층수를 1층으로 고정 |
| 기사 | 장문의 기백 | 2,000자 이상 저장 시 1시간 ATK +20% |
| 어휘 마도사 | 어휘 폭발 | INT 비례 광역 마법: 일반 몬스터 최대 3마리 동시 처치 |
| 어휘 마도사 | 사전 소환 | 수수께끼 룸 자동 정답 확률 +30% |

**공용 스킬** (클래스 무관, 교감·업적으로 습득)

| 스킬 | 습득 조건 | 효과 |
|---|---|---|
| 마음의 메아리 | 친밀도 Lv.10 | 정령의 부탁 보상 2배 |
| 백만 문자의 관록 | 누적 100만 자 업적 | 마나 획득 +5% |
| 도감 수집가의 눈 | 도감 50% 등록 | 희귀 몬스터 조우율 +10% |

# 3. 먹이 & 교감 시스템 (다마고치 코어)

## 3.1 포만감 (밸런스 개정)

| 규칙 | 값 (v1.0 → 본 문서 개정) |
|---|---|
| 회복 | 저장 글자 100자당 **+8%p** (기존 +5%p에서 상향) |
| 오늘의 첫 저장 보너스 ★신설 | 그날 첫 저장은 포만감 회복 **2배** — 하루 한 번만 써도 유지 가능하게 |
| 자연 감소 | 시간당 **−3%p** (기존 −4%p에서 완화. 하루 −72%p) |
| 탐험 조건 | 포만감 50% 이상 |
| 0% | '기절' 상태. 사망 없음 (1.5 기분 표 참조) |

> 목표 체감: **하루 1,000자 유저가 아침·저녁 두 번 저장하면 탐험 가동률 60~80% 유지.**
> 하루를 완전히 걸러도 기절까지는 이틀의 여유가 있다.

## 3.2 친밀도 ★신설

포만감이 "생존"이라면 친밀도는 "관계"다. 누적형 수치로, 내려가지 않는다.

**획득 수단**

| 행동 | 친밀도 |
|---|---|
| 오늘의 첫 저장 | +5 |
| 쓰다듬기 (상태창의 정령 탭) | +1 (1일 10회까지 유효) |
| 간식 주기 (아이템) | +2 |
| 정령의 부탁 완료 | +10 |
| 정령의 편지 읽기 | +5 |

**친밀도 레벨과 특전** (필요치: 레벨 × 100)

| Lv | 관계 | 정령의 호칭 변화 | 특전 |
|---|---|---|---|
| 1 | 낯섦 | "저기요…" | — |
| 3 | 친구 | "작가님!" | 로그 대사 확장 1차 |
| 5 | 단짝 | 유저 프로필 이름을 부름 | **장신구 슬롯 해금** |
| 7 | 가족 | 애칭 사용 | 로그 대사 확장 2차, 전용 모션 |
| 10 | 운명의 단짝 | — | 공용 스킬 [마음의 메아리], 특별 일러스트 로그 |

## 3.3 교감 액션

| 액션 | 내용 |
|---|---|
| 쓰다듬기 | 상태창의 정령을 탭 → 하트 이펙트 + 성격별 반응 대사 |
| 간식 주기 | 소모품 [간식] 사용: 포만감 +10%p, 친밀도 +2 |
| **정령의 부탁** ★신설 | 1일 1회 랜덤 발생. 글쓰기와 교감을 잇는 마이크로 퀘스트. 예: "오늘 하늘이 어땠는지 한 줄만 써 줘" (날씨 단어 포함 저장 시 완료) / "'고마워'라고 한 번만 써 줘" / "500자만 더 쓰면 좋은 게 나올 것 같아!" |

## 3.4 정령의 편지 ★신설 (주간 리포트의 게임화)

- **매주 월요일 첫 실행 시** 상태창에 편지 봉투가 도착한다.
- 내용: 지난주 통계(총 글자 수, 가장 많이 쓴 시간대, 최고 던전 기록, 가장 자주 쓴 단어)를
  **정령의 성격 말투**로 요약. 생산성 리포트가 곧 팬레터가 된다.

> 예시 (성격: 먹보 / 이름 예시: 에코)
> *"작가님! 지난주에 글을 4,200자나 주셔서 배가 아주 든든했어요.
> 수요일 밤 11시의 글이 제일 고소했어요. 덕분에 '캐시 파일의 늪' 12층까지 내려갔다구요.
> 이번 주도… 간식… 아니 글, 기다릴게요. — 에코 올림 🍙"*

## 3.5 방치·복귀 설계 원칙

1. **죽음 없음.** 최악의 상태도 '기절'과 '겨울잠'뿐.
2. 장기 방치 복귀 시 꾸짖지 않고 환영한다: 재회 연출 + 복귀 선물(간식 3개 + 마나 500).
3. 오프라인 정산(5.1)으로 "내가 없는 동안의 이야기"를 보상으로 준다.

## 4.2 감정 날씨 시스템 ★신설

최근 24시간 저장 텍스트의 **긍정/부정 단어 비율**로 게임 세계의 날씨가 바뀐다.
유저의 마음이 정령의 하늘이 된다 — 이 게임의 감성 핵심.

| 날씨 | 판정 | 게임 효과 | 연출 |
|---|---|---|---|
| 맑음 ☀️ | 긍정 우세 | 드롭률 +10% | 밝은 배경, 경쾌한 로그 |
| 흐림 ⛅ | 중립/판정 불가 | — | 기본 |
| 비 🌧️ | 부정 우세 | [스트레스 결정체] 드롭률 3배, 던전에 '빗물 웅덩이'(휴식 강화) 룸 출현 | 정령이 우산을 쓰고 위로 대사를 건넴 |
| 무지개 🌈 | 어제 비 → 오늘 긍정 전환 | 6시간 동안 모든 보상 +25% | 특별 로그: *"비 갠 뒤의 하늘처럼, 오늘의 글은 유난히 반짝인다."* |

> **설계 의도**: 힘든 날의 글쓰기가 "손해"가 아니라 **다른 종류의 보상**이 되게 한다.
> 부정 단어를 쓴 유저에게 벌점은 절대 없다.

## 4.3 실제 시간·계절 연동 ★신설

| 요소 | 내용 |
|---|---|
| 밤/낮 | 실제 시각에 따라 상태창 픽셀 배경이 낮/노을/밤으로 전환 (별빛 정령은 밤에 강화) |
| 계절 한정 몬스터 | 봄: 벚꽃 슬라임 / 여름: 장마 젤리 / 가을: 낙엽 골렘 / 겨울: 눈사람 미믹 — 처치 시 도감 '계절 페이지'에 등록 |
| 기념일 | 연말·새해 등에 1회성 이벤트 로그와 한정 간식 지급 (서버 없이 로컬 날짜로 판정) |

## 5.4 보스전 규칙

- 각 던전 **10층마다 중간보스**, 최상층에 **던전 보스**.
- 보스전은 **3~5틱에 걸친 장기전**으로, 틱마다 공방 로그가 이어진다 (연재소설 같은 긴장감).
- 승리: 대량 마나 + 확정 장비 드롭 + 도감 등록. 패배: 5층 후퇴 + '기세' 버프(5.1).

## 5.5 속성 상성 (심플 규칙)

로그라이크의 양념 수준으로만 사용한다. 유리 +20% / 불리 −20%.

```
불 → 바람 → 땅 → 물 → 불   (순환 우위)
빛 ↔ 그림자                 (상호 우위: 서로에게 +20%)
기계 · 무(투명)              (상성 없음)
```

- 정령의 속성은 종족(1.2)이 결정한다. 몬스터 속성은 도감(6장)에 표기.
- 상성이 불리한 던전은 로그에 힌트를 준다: *"{이름}이(가) 이곳의 공기를 어려워한다…"*

## 7.5 강화 시스템 ★신설

- 마나 + 재료로 장비를 **+1 ~ +5** 강화. 단계당 기본 효과 +10%.

- +5 도달 시 장비 이름이 진화한다: *낡은 연필검 → "잘 깎인 연필검"*, *백스페이스 방패 → "언두(Undo)의 방패"*.

## 8.1 의뢰 게시판 ★신설 (일일/주간 퀘스트)

던전 입구의 '의뢰 게시판' 콘셉트. 매일 3개(풀에서 랜덤), 매주 2개.

| 구분 | 의뢰 예시 | 보상 |
|---|---|---|
| 일일 | 오늘 300자 쓰기 / 저장 2회 / 쓰다듬기 3회 / 키워드 1회 발동 / 제목 있는 메모 1개 작성 | 마나 150~300, 간식 1 |
| 주간 | 주 5일 저장 / 누적 3,000자 / 보스 1회 처치 / 일일 의뢰 10회 완료 | 희귀 재료, 마나 1,500 |

- 의뢰는 **전부 "어차피 하던 글쓰기"로 달성 가능**해야 한다. 게임을 위한 별도 노동을 요구하는 의뢰 금지.

| 규칙 | 내용 |
|---|---|
| 정의 | 하루 1회 이상 저장 시 스트릭 +1 |
| 보상 | 3일: 간식 / 7일: 희귀 재료 + 마나 500 / 30일: 칭호 [한 달의 불꽃] / 100일: 전용 배경 |
| 끊김 | **벌칙 없음.** 보상 진행만 초기화 |
| 불씨 | 아이템 [스트릭의 불씨](주간 의뢰 보상): 하루 공백을 1회 보호 |

## 8.3 업적 (누적 마일스톤)

| 업적 | 조건 | 보상 |
|---|---|---|

## 8.4 칭호 시스템 ★신설

- 업적·도감·환생에서 획득. **유저(작가)에게 붙는 장식**으로, 상태창 이름 옆에 1개 장착.
- 소소한 스탯 보너스(+1~3% 수준)를 부여하되, 핵심은 **정체성 표현**이다.
- 명예의 전당 기록에도 은퇴 당시 장착 칭호가 함께 남는다.

# 9. 환생 & 세대 시스템

## 9.1 은퇴 절차

1. Lv.100 도달 시 상태창에 '은퇴' 버튼 개방 (강제 아님 — 계속 키워도 됨).
2. 은퇴 확정 시 **은퇴식 연출**: 정령이 그동안의 기록을 회고하는 **마지막 편지**를 남긴다.
   *"작가님과 함께 쓴 84,000자를 전부 기억해요. 다음 아이를 잘 부탁해요. — {이름}"*
3. 명예의 전당에 기록 → 환생 포인트 정산 → 새로운 알 선택.

## 9.2 명예의 전당 (기록 항목 확장)

| 기록 항목 |
|---|
| 세대 수 / **이름(유저가 지은 이름)** / 종족 / 최종 클래스 / 장착 칭호 |
| 함께 쓴 총 글자 수 / 함께한 일수 / 최고 도달 던전·층수 / 도감 등록 수 |

## 9.3 환생 보상: 기본 배율 + 영구 업그레이드 트리 ★확장

**기본 배율 (자동 적용)** — 원안 유지

- 첫 환생: 글자당 마나 획득 **1.5배**. 이후 환생마다 **+0.25배** 누적.

**환생 포인트(EP) & 업그레이드 트리** — 신설

- 은퇴 시 EP 획득: 기본 10 + (도감 등록 ÷ 10) + (달성 업적 ÷ 5).
- 3계열 트리에 자유 투자 (노드당 1~3 EP, 계열당 5노드):

| 계열 | 노드 효과 (누적) |
|---|---|
| 풍요 | 마나·Exp 획득 +10% / 노드 |
| 유대 | 포만감 자연 감소 −5%, 친밀도 획득 +10% / 노드 |
| 탐험 | 탐험 틱 −5%, 드롭률 +5% / 노드 |

## 9.4 유산 시스템 ★신설 — "가보"

- 은퇴 시 장비 1개를 **가보**로 지정 → 다음 세대가 Lv.10부터 사용 가능.
- 가보에는 **전대 정령의 이름이 새겨진다**: *"에코의 잘 깎인 연필검"* — 이름 시스템과 세대 서사의 연결 고리.

## 9.5 세대 서사

- 새 알 부화 시, 신입 정령이 전당의 선대를 언급한다: *"전당에 계신 {선대 이름} 님처럼 되고 싶어요!"*
- 세대가 쌓일수록 던전 NPC(떠돌이 상인 등)가 선대를 회상하는 대사 추가 — 축적의 감각.

# 부록. 로그 텍스트 가이드

로그는 이 게임의 그래픽이자 연출이다. 모든 로그는 템플릿 + 변수로 생성한다.

**템플릿 변수**: `{이름}`(유저가 지은 정령 이름), `{몬스터}`, `{아이템}`, `{던전}`, `{층}`, `{마나}`

**작성 원칙**

1. 한 줄 40자 이내. 이모지·특수문자 남용 금지 (픽셀 폰트 가독성).
2. 유저를 "작가님/당신"으로 지칭 — 정령이 유저에게 말을 거는 구도.
3. 성격(1.3)별 어미 변형 세트를 둔다. 같은 사건도 성격 따라 다르게 들리게.

**예시 (같은 사건, 성격별)**

| 성격 | 로그 |
|---|---|
| 성실함 | "{이름}: {몬스터} 1마리 처치를 보고드립니다. 전리품 {아이템} 확보." |
| 먹보 | "{이름}이(가) {몬스터}를 해치웠다! …이거 먹는 건 아니래요. {아이템} 획득." |
| 겁쟁이 | "{이름}이(가) 벌벌 떨면서도… 해냈다! {몬스터}를 물리쳤다…!" |
